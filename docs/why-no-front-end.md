# Why this desk has no front end

A call review consists of source passages, agreed actions, owners, dates and a review record. You can ask a coding agent to read the transcript, propose next steps and write checked records through one CLI. Your database stays yours and the weekly questions can change without waiting for a reporting screen.

This base starts after a transcript exists. It does not join meetings, record audio, transcribe speech, identify speakers, play video, provide live prompts, synchronise calendars or update another system. It is useful with authorised transcript downloads and your existing capture tool. Enterprise DNA can scope connections and a private web front end for the workflow you need.

npm run view produces three branded, read-only HTML reports. npm run docs produces call briefs, coaching notes and retention working papers. They are local files, not an application or a shared access portal. Mobile capture, offline recording and interactive transcript playback need other tools. The coding agent is where records change.

Keep these reports private. The template uses a remote font stylesheet; for disconnected or restricted installations remove that stylesheet and use system fonts. No database contents are sent by this repo, and no model API calls are made. When using an external coding agent, configure its handling of private business data before giving it transcripts.
